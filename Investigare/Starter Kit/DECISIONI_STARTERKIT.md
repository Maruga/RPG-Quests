# Decisioni Starter Kit — fissate dall'utente il 2026-08-09

> Questa è la fonte delle scelte del kit. Non si riapre nulla di ciò che è scritto qui
> senza una nuova decisione esplicita dell'utente.

## Impianto

- **Cartella indipendente**: solo copie, nessun rimando esterno, doppioni voluti.
  Una volta consolidato, il kit resta effettivo **per mesi** senza ricontrolli.
- **Avventura**: *L'Ultima Cena di Tanaka* (Sake) — copiata e adattata. La trama non si tocca.
- **Niente passaggio del giorno**: Sake si svolge in una serata continua (verificato:
  3 scene, 45-60 min) — soroban, recupero notturno, guarigione notturna, ritiro del dado Ki
  e riduzione notturna del costo Gou **non esistono** nel kit.
- **Schede pregenerate**: i 5 investigatori, si gioca subito.

## Le regole del libretto — decise una per una

| Regola | Decisione |
|---|---|
| **Ki** | **Tirato**: 2d6 prendi il più alto, **l'1 si ritira** (sempre). Ki max = attributo più basso + dado. Niente punti comprati |
| **Genkai** | Dentro, completo (crollo a Ki ≤ 3, crisi, rientro) |
| **Donare Ki** | Dentro: si può **sempre**, 1 Ki per situazione — compreso rialzare un compagno in Genkai (è lo spirito del gioco) |
| **Kyōryoku (+1 sui tiri)** | **FUORI** — cosa diversa dal donare Ki: complica e dà poco alla prima serata |
| **Nasake** | **Dentro** — è per chi ama il roleplay |
| **Tiri di pressione** | **Dentro**, versione essenziale |
| **Gou** | Le schede tengono le **3 opzioni** ciascuna: le **15** spiegate per esteso; **gli altri 6 solo per nome** («nel gioco completo sono 21» — far capire che il gioco è profondo). **Costo fisso** per uso (niente raddoppio: non c'è la notte) |
| **Kage** | **Spiegato per intero** (cos'è, la scena giocata, il voto del tavolo ±1) ma **opzionale** per la prima serata; nota: nel gioco completo vive ed evolve |
| **Enja** | Dentro **senza regole**: puoi contattarlo **una volta per avventura**, gratis; nota che il gioco completo lo regola |
| **En** | Dentro — e la Guida GM ha **tabelle d'aiuto** (comportamento del PNG per livello, esempi, quando muoverlo) |
| **Satori** | Dentro (1 per sessione) |
| **Senmon** | Sistema completo fuori; sulle schede «Lotta + una specialità (+1 quando pertinente)»; nel libretto un **elenco di nomi** per far intuire il catalogo |
| **Combattimento** | **Niente regole.** Nel libretto solo un accenno («il gioco completo ha il modulo Lo Scontro»). L'azione sta nel **finale opzionale** dell'avventura (vedi sotto) |
| **Distretto/enti** | Fuori: Yamada consegna quello che serve, nessun tiro d'ente |
| **Shugyō/crescita** | Fuori (è una one-shot) |

## Il finale opzionale (solo nella copia del kit)

Se il GM vuole giocarlo: **il colpevole messo alle strette estrae una pistola**.
Indicazioni essenziali per la scena nella Guida GM — dura poco per costruzione:
**o si arrende, o si toglie la vita alla giapponese** (meglio la morte del disonore).
L'originale di Sake nella cartella madre resta senza questo finale.

## Guida GM

Passo-passo per il primo GM, **senza binari**: il GM presenta la situazione, **i giocatori
decidono come muoversi**. Gli indizi si danno sempre. Come usare gli handout, tabelle En,
errori tipici, il box del finale opzionale.

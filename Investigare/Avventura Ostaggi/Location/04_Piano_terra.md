# Piano terra

| Zona | Stato iniziale / dettaglio utile |
|---|---|
| Ingresso clienti | Chiuso dall’interno; può essere aperto per una consegna o una liberazione |
| Salone | Sedie rovesciate, numeri della coda ancora accesi; ostaggi radunati lontano dalla vetrata |
| Sportelli | Cassetti di contanti ignorati; nessun sacco riempito di banconote |
| Porta personale | Divide salone e corridoio; una guardia controlla chi la attraversa |
| Angolo acqua / fotocopiatrice | Nicchia fuori dalla visuale diretta del salone, ma raggiungibile dal corridoio; permette solo brevi conversazioni sussurrate |
| Archivio amministrativo | Copia cartacea di [D03](../Documenti/D03_Cassetta.md); non contiene il dossier segreto |
| Porta posteriore | Chiusa a chiave; il vicedirettore possiede la chiave di servizio. Nessun accesso garantito soltanto perché si trova sul retro |

**Informazioni osservabili:** denaro non toccato; persone che chiedono istruzioni via radio; rumori di lavoro provenienti dal basso. I rumori indicano attività, non il modello di attrezzatura o un tempo esatto di completamento.

**Presenze:** [tabella della banca](02_Banca.md). **Collegamenti:** [schema dell’edificio](02_Banca.md#collegamenti-fisici--fonte-unica).

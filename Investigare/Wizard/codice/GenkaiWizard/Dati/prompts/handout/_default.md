## Tipologia: documento generico → `ho-doc`

Nessun file specifico per questo tipo: produci un documento sobrio e coerente con la `descrizione`.
`<div class="ho-foglio ho-doc">` con:
- `.ho-intestazione` (ente/organo se ha senso: `ente` + `ente-jp` + `tipo-doc`),
- `<dl class="ho-meta">` con i metadati utili (n° pratica, data, oggetto, protocollo),
- il corpo in `<h2>`/`<h3>`/`<p>` secondo ciò che chiede la descrizione,
- eventuale `<div class="ho-firma">` e/o `<div class="ho-timbro">`.

Usa i dati veri del caso; taglio burocratico giapponese di fine anni '90.

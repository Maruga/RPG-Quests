## Ordine del Round

```
1. SORPRESA (solo 1° round) — 1d6 per lato (1-2 sorpreso)
2. INIZIATIVA — 1d6 per lato (più alto vince)
3. VINCITORE:   Missile → Magic → Move → Melee
4. PERDENTE:    Missile → Magic → Move → Melee
5. MORALE (se serve) — 2d6
6. Nuovo round
```

**Dichiarazioni PRIMA dell'iniziativa:** magia · ritirata · fuga · cambio arma

## Direzione dei Tiri

| Tipo           | Tiro         | Regola                              |
| -------------- | ------------ | ----------------------------------- |
| **TxC**        | 1d20 + mod   | **≥** (THAC0 − CA bersaglio)        |
| **TS**         | 1d20         | **≥** valore TS scheda              |
| **Attributo**  | 1d20         | **≤** valore attributo scheda       |
| **Morale**     | 2d6          | **≤** morale mostro = tiene         |

**THAC0 — Formula:** `CA colpita = THAC0 − (d20 + mod)`
- **Nat 20** = colpo sicuro · **Nat 1** = fallimento sicuro

## Regole Lampo

| Cosa                  | Come                                                        |
| --------------------- | ----------------------------------------------------------- |
| Armi a 2 mani         | Attaccano **per ultime** nel turno                          |
| Iniziativa pari       | Azioni simultanee (morte reciproca possibile)               |
| Magia interrotta      | Colpito prima/durante → slot perso                          |
| Velocità incontro     | Base ÷ 3 (120' = 40'/round)                                 |
| Chi lancia magia      | Max ½ velocità incontro (house rule)                        |
| Doppio movimento      | Fuori mischia + niente attacco = ×2 velocità                |
| Ritirarsi             | ½ velocità, niente attacco, nessuna penalità                |
| Fuggire               | Velocità piena, nemico +2 TxC e ignora scudo                |
| Cambio arma           | Costa 1 round intero                                        |

## Morale — Quando Tirare

Primo nemico ucciso · 50% nemici morti · Leader morto · Situazione critica (DM)

**I PG non tirano morale** (decidono i giocatori)

# Token Mutanti — Prompt Completi

> Prompt pronti da copiare e incollare per generazione immagini.
> Formato: quadrato 2,5 cm per stampa. 9 token per foglio + 1 boss.

---

# ISTRUZIONI STAMPA

Per ottenere token da 2,5 cm:
1. Genera immagini quadrate (1024x1024 o 512x512)
2. In un programma di grafica, crea un foglio A4
3. Disponi 9 immagini in griglia 3x3
4. Ridimensiona ogni immagine a 2,5 x 2,5 cm
5. Stampa e ritaglia

**Oppure:** Genera direttamente una griglia 3x3 con il prompt indicato.

